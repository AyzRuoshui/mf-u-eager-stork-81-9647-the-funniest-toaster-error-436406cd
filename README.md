# The Funniest Toaster Error Message

`main.ts` writes a single deterministic error line to `/output/entry.txt`.

The text is a fixed firmware-style joke: a toaster reports `E07` and lists toast shades, ending with the wrong "shade" being emotional damage. It has no network calls, no random values and no runtime dependencies beyond Node 22 standard libraries.
